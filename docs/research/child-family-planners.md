# 儿童可视化日程与家庭协作产品调研

调研日期：2026-11-11。对应 [调研儿童家庭学习计划产品，为首版方向提供依据](https://github.com/Limilylee/tasklist/issues/1)、[调研儿童可视化日程与家庭协作产品](https://github.com/Limilylee/tasklist/issues/3)。

## 结论

这组产品中，**Brili 的儿童执行界面、Goally 的亲子分工、FamilyWall 的固定活动与家庭共享、MyStudyLife 的学期和假期例外**分别有参考价值。本报告未验证任何具体家庭或设备的适配情况。尤其不能把存在 Android 版本等同于任意学习平板可安装、可同步或可靠提醒。

**当前优先级判断（研究推论）**：如要验证现成工具，先验证 FamilyWall 的网页和家庭共享是否能接受，再补一个孩子易懂的执行方式；如要设计自己的工具，采用“家长准备、孩子在允许范围内排序并执行”的分工。Brili 当前分发状态、Goally 的专用硬件方向、MyStudyLife 的年龄定位，使它们更适合设计研究，而不是低龄家庭立即购买的首选。

## 方法与场景

本报告是**官方资料审阅和场景推演，未注册产品账号、未付费、未在目标设备安装或执行完整任务**。浏览器打开官网与阅读帮助不算实际试用。除明确写“事实”的资料说明外，适配结论、建议与预期结果均是推论。

本报告公开部分仅包含产品资料与**通用假设场景**，不记录具体家庭、儿童或设备资料。假设家长在下午接到临时作业、晚间安排学习；孩子还有额外练习和固定兴趣课，需要日、周、假期计划。

统一推演：家长录入学校作业后追加练习；孩子选择两个灵活任务的先后顺序；中途休息；当天有固定课；周末临时调课；假期暂停学校课表。重点核查谁能改、固定时间是否会被拖动、任务超预算怎么办、假期修改是否污染平日模板。该推演不是实测成绩。

## 场景推演：每款解决哪一段

1. **下午接收学校作业，再追加练习**：四款都应先按人工录入验证；本次未发现学校聊天群作业官方接入证据。FamilyWall 的快速任务添加可带日期、时间、责任人和备注，适合家长收集；Goally 家长改动需要儿童设备联网才同步。其余同步延迟未实测。[FamilyWall 帮助](https://support.familywall.com/en/support/solutions/articles/47001271445-use-task-quick-add-in-list)、[Goally FAQ](https://getgoally.com/faqs/)
2. **孩子先选哪个灵活任务**：Brili/Goally 展示“当前做什么”有明确证据，但均未证实孩子能在家长规定范围内重排；FamilyWall/MyStudyLife 的普通编辑权限也不能等同于这种受限选择。若这是核心需求，应列为实际试用的首个验收点。
3. **约定时间必须收尾**：Brili 历史设置区分固定开始与固定结束；固定结束模式可能因超时缩短剩余活动。对作业不能机械压缩时长，应显示“已超预算，待家长处理”更合适。这是产品设计推论，不是 Brili 已有该保护。[Brili 设置帮助](https://support.brili.co/support/solutions/articles/14000043181-setting-up-a-routine)
4. **固定兴趣课与作业冲突**：FamilyWall 适合先把固定活动放进共享日历，孩子当天任务另列；MyStudyLife 也有课外活动规划。未查到这四款能自动保证“固定课不动、自由任务自动填缝且不超过学习窗口”。[FamilyWall 官网](https://www.familywall.com/)、[MyStudyLife 商店说明](https://apps.apple.com/us/app/my-study-life-school-planner/id910639339)
5. **周末单次调课、假期暂停学校任务**：FamilyWall 的官方连接器说明支持修改单次、当次以后或整串重复活动，这是重复例外的设计证据，未实际测试其各客户端操作。公共节假日显示不能证明学校课自动暂停。MyStudyLife 的 Holiday 暂停重复课最明确，但不会取消一次性课/考试，也不能推断会暂停全部作业。[FamilyWall 事件说明](https://support.familywall.com/en/support/solutions/articles/47001308120-use-familywall-with-claude)、[节假日帮助](https://support.familywall.com/en/support/solutions/articles/47001239822-how-to-display-or-hide-holidays-in-familywall-)、[MyStudyLife FAQ](https://mystudylife.com/faqs/)

## 可借鉴的设计与下一步验收

以下为研究建议，不是已决定实现的范围：

- 家长端以“收集当天作业、设置硬约束、发布计划”为主；儿童端仅显示今天、下一步、时间余量和完成按钮。借鉴 Brili/Goally 的角色分离，避免要求低龄儿童孩子维护复杂课表。
- 数据上分开固定活动、灵活任务与重复模板。固定课是日历事件；学习任务有预计时长、截止日期和来源；假期是一段例外日期，不应靠批量删除平日模板来实现。
- 孩子能选择两个灵活任务的顺序，但固定课和 约定收尾时间不随拖动改变；挤不下时请求家长调整，不静默压缩练习或把未做项目算完成。
- 日计划是今天的实例，周计划用于负荷和固定活动，假期计划用于临时替换模板；可借鉴 MyStudyLife 的 Holiday 例外，但需覆盖不同学校的校历、调休和假期练习。

实际选择前只需先做一次短场景验收：家长桌面端创建两项任务 → 手机追加一项 → 目标平板联网接收 → 孩子改变允许顺序并完成一项 → 家长看到结果 → 断网再联网检查重复/丢失 → 熄屏到提醒时间 → 测一次周末单次改动和一段假期。记录每个平台版本、获取渠道、账号地区、中文界面、所需付费档、同步耗时及后台提醒结果。没有这些记录前，不给出“已经可用于目标平板”的结论。
